1. Open the English deck and keep the Chinese deck as a reference.
2. Present Slides 1–3 without touching the device.
3. On Slide 4, run only the verified Guided Rewrite golden path.
4. Continue Slides 5–10 and stop speaking by 9:40.
5. Use the final five minutes for Q&A; the script contains short answer modules.

1. 主講使用英文簡報，繁中版留作參考。
2. 第 1–3 頁先講清楚問題和流程，不操作裝置。
